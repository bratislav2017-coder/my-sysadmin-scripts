Мониторинг ресурсов Linux с записью результатов в monitor.log.

Скрипт каждые 5 секунд добавляет в лог временную метку и результаты команд free -h, df -h и uptime.

Требования: Linux, Bash, date, free, df, uptime, sleep.

Проверка синтаксиса:
bash -n script.sh

Запуск:
chmod +x script.sh
./script.sh

Остановка:
Ctrl+C

Лог monitor.log сохраняется рядом со скриптом. Повторный запуск дописывает результаты, сохраняя предыдущие записи.

Интервал задаётся константой N в script.sh. Интерактивный ввод не требуется.

При отсутствии необходимых команд или невозможности записи лога скрипт завершается с ошибкой.

sample_output.txt содержит настоящий пример результатов запуска.
